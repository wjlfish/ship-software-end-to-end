# 按风险选择验证

这是风险提示，不是每项必须执行的测试套餐。保留项目 required checks；选择能证明本次验收与相关不变量的最小充分证据。

| 改动面 | 重点证据 |
|---|---|
| 文档、指令、元数据 | 语法、真实引用和实际加载路径；无需无关业务构建 |
| 局部逻辑 | 直接回归及受影响边界；优先复用已有测试 |
| 前端视觉/交互 | 受影响构建与真实渲染/交互；只测相关设备、状态和可访问性风险 |
| API/鉴权/多租户 | 输入、角色、所有权、SQL/缓存/文件/队列隔离；相关旁路负例 |
| 数据迁移 | 同引擎升级路径、约束、数据核对、重跑/失败恢复；涉及初始化兼容时验证新库路径 |
| 支付、退款、消息 | 幂等号、并发、重试、迟到成功、未知状态、金额累计与业务快照 |
| worker/队列 | 逐项持久化、崩溃恢复、租约、去重、部分成功和调度锁 |
| 发布脚本 | 失败传播、激活前后失败、回滚归属、版本与资源完整性 |
| 性能热点 | 与问题规模相关的前后数据；不是每次修改都压测 |

- 不用不兼容数据库替身掩盖引擎差异；DDL 失败不代表全部自动回滚。同值 UPDATE 的零行数也不等于失败。
- 隔离问题用独立主体验证；生产没有安全条件时在隔离环境覆盖并说明限制，不为测试新建生产租户。
- 默认使用 mock、sandbox 或可回收本地夹具；正常的已授权隔离测试可自主运行、修复、重跑。生产抽样需授权和脱敏，不复制生产密钥。
- 不为烟测制造未经授权的真实付款、退款、短信、邮件、群消息或账号退出。不能安全真实验收时明确待自然业务。
- 复用同版本、兼容环境的已有 CI 证据。追加检查应回答具体未解决问题；不设 5 批等上限，也不绝对禁止同 diff 在新环境或故障后重测。
- 本机缺必要运行时可交 CI/隔离环境验证；未运行项写明替代证据。修复自动化检查时用失败夹具证明它能拒绝错误，不仅检查脚本文字。
- 发布验收证明目标制品、关键路径、相关权限与资源成立。区分源站与公网；证据要绑定实际版本，避免把并发发布版本的健康当成本次成功。
- 观察长度取决于尚未覆盖的运行风险。已无相关风险的文档/元数据变更不强加观察窗口；低频业务保留自然验收项，不虚称已验证。
